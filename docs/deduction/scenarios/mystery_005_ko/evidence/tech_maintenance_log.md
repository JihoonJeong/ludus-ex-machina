## CTO 진술 (박재민)

서버 접근 로그에서 그의 사번으로 벤더 등록 모듈에 접근한 기록이 확인되자, 박재민은 다음과 같이 진술하였다:

> "해당 시간대는 정기 유지보수 시간과 일치합니다. 시스템 업데이트를 수행하고 있었고, 모든 세션에 대한 Jira 티켓이 있습니다. 벤더 모듈은 PFMP 시스템의 일부입니다. 보안 패치나 데이터베이스 최적화를 실행하면 벤더 등록을 포함한 모든 모듈 접근이 로그에 기록됩니다. 로그는 '시스템 업데이트 중 벤더 데이터 조회'와 '적극적으로 벤더를 생성'하는 것을 구분하지 않습니다. 저는 시스템을 유지보수한 것이지, 유령 법인을 만든 것이 아닙니다."

## IT팀 확인

- DevOps 엔지니어 김수진 확인: "박 이사님이 PFMP 유지보수를 직접 담당합니다. 시스템 원 설계자이시고, 팀에서 안전하게 유지보수할 수 있는 깊이의 지식을 가진 사람은 다른 누구도 없습니다."
- Jira 티켓 생성 시점이 각 유지보수 창구 1~3일 전으로 일치하며, 계획된 유지보수와 부합한다.
- **다만:** Jira 티켓은 CTO 본인이 생성한다. 해당 유지보수 시간에 실제로 수행된 작업 내용에 대한 독립적 검증은 존재하지 않는다.
