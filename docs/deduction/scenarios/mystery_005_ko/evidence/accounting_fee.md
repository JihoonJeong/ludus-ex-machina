# 별도 컨설팅 계약 — 강도현 (세정회계법인)

**출처:** 페이브릿지 계약 기록 + 세정회계법인 공시

## 확인 사항

정규 감사 계약(연 6천만 원) 외에, 페이브릿지는 **강도현 개인**(세정회계법인 소속이 아닌 개인 자격)과 별도 컨설팅 계약을 체결하고 있었다:

### 계약 상세

| 항목 | 내용 |
|------|------|
| 계약명 | "전략적 재무 자문 서비스" |
| 당사자 | 페이브릿지 ↔ 강도현 (개인 자격) |
| 체결일 | 2025년 9월 15일 |
| 보수 | 월 500만 원 + 성과 보너스 |
| 범위 | "세무 최적화, M&A 자문, 투자자 관계 지원" |
| 승인자 | 대표이사 김태원 |
| 기간 | 12개월 |

### 잠재적 이해충돌

강도현은 동시에 다음 두 역할을 수행하고 있었다:
1. **외부 감사인** (세정회계법인 소속) — 페이브릿지 재무제표 검증 책임
2. **개인 컨설턴트** (개인 계약) — 재무 전략 자문

이 구조는 외부감사법상 감사인 독립성 요건을 잠재적으로 위반한다.

### 강도현 진술

> "컨설팅 계약은 감사 업무와 완전히 분리되어 있습니다. 제가 자문한 거래에 대해서는 직접 검토에서 배제하였습니다. 대표이사가 회사 재무에 대한 저의 이해도를 보고 접근하신 것입니다. 이해충돌은 없습니다."

### 세정회계법인 입장

세정회계법인은 경찰 수사 전까지 개인 컨설팅 계약의 존재를 인지하지 못하였다. 법인 차원의 내부 검토가 시작되었다.

### 경찰 판단

- 컨설팅 보수(감사 6천만 원 + 컨설팅 6천만 원 = 연 1억 2천만 원)는 페이브릿지와의 관계 유지에 상당한 재정적 이해관계를 형성한다.
- 그러나 컨설팅 계약을 유령 법인 이체에 직접 연결하는 증거는 없다.
- 횡령을 발견한 감사 보고서는 강도현 팀이 작성하였다 — 만약 그가 횡령에 가담했다면, 자신의 팀이 이상 거래를 적발하는 것은 비정상적이다.
- **판단: 이해충돌은 있으나, 동기는 컨설팅 수입 유지이지 횡령이 아니다. 오히려 본인 팀이 횡령을 발견한 점이 관여 가능성에 반하는 정황이다.**
