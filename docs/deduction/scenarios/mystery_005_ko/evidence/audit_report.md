# 내부 감사 보고서 — 페이브릿지(PayBridge Inc.)

**작성:** 세정회계법인 (강도현 파트너)
**일자:** 2026년 3월 3일
**분류:** 대외비

## 감사 결과 요약

2025년 4분기 정기 재무 검토 과정에서 다음과 같은 이상 거래가 확인되었다:

### 비인가 자금 이체

2025년 12월부터 2026년 2월까지 페이브릿지 운영 계좌에서 3개 법인으로 총 12억 원이 이체되었다:

| 수취인 | 금액 | 일자 | 청구서 명목 |
|--------|------|------|-----------|
| 블루웨이브 솔루션즈 | 3억 8천만 원 | 2025.12.18 | "클라우드 인프라 업그레이드" |
| 넥스트폼 디지털 | 4억 5천만 원 | 2026.01.22 | "AI 모델 라이선스 비용" |
| 그린필드 데이터 | 3억 7천만 원 | 2026.02.14 | "데이터 컴플라이언스 컨설팅" |

### 유령 법인 확인

3개 법인 모두 2025년 10~11월 사이에 설립되었다. 법인 등기부 확인 결과:

- **블루웨이브 솔루션즈:** 2025.10.12 설립. 주소: 판교 가상 오피스. 직원 없음, 웹사이트 없음, 세금 신고 이력 없음.
- **넥스트폼 디지털:** 2025.10.28 설립. 주소: 강남 가상 오피스. 직원 없음, 웹사이트 없음, 세금 신고 이력 없음.
- **그린필드 데이터:** 2025.11.05 설립. 주소: 여의도 가상 오피스. 직원 없음, 웹사이트 없음, 세금 신고 이력 없음.

3개 법인 모두 동일한 법인 설립 대행업체를 이용하였다. 해당 대행업체는 온라인으로 최소한의 본인 확인만으로 설립이 이루어졌다고 확인하였다.

### 자금 추적

3개 법인으로 이체된 자금은 이후 2개 중간 계좌를 거쳐 신한은행 최종 계좌로 이동하였다. 최종 계좌 명의인 정보는 은행에 요청 중이나 아직 세정회계법인에 제공되지 않았다.

### 결론

해당 이체 건들은 유령 법인을 이용한 체계적 횡령의 특징을 보인다. 청구서에 기재된 서비스는 페이브릿지가 계약한 기록이 없다. 내부 승인 경위에 대한 조사가 진행 중이다.
